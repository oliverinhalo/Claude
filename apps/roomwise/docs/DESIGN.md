# Roomwise — design

Feeling: **warm**. Like a floor plan drawn on good paper.

- Type: Fraunces (variable, self-hosted) for headline and big amounts; system sans for UI. 1.25 scale from tokens.
- Colour: warm paper neutrals; terracotta accent (`--accent`), deeper in light for contrast, desaturated peach in dark. Room swatches use a 6-colour categorical set at 3:1 against surface.
- Shape: 4px radius, borders over shadows. Spacing from the 4/8/12/16/24/32 scale.
- Motion: 200ms width transition on the floor-plan strip; disabled under reduced motion.
- **Signature: the floor-plan strip** — one bar whose segment widths are each room's share, so fairness is visible at a glance and changes live as you tick perks.
